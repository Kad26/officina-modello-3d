# 9. Keyboard shortcuts

SketchCraft uses SketchUp's default shortcuts. Press **?** in the app for the
full list, and **Shift+S** to find any command by name.

| Key | Tool | Key | Tool |
| --- | --- | --- | --- |
| Space | Select (hold to orbit) | M | Move (Option/Ctrl copies) |
| L | Line | Q | Rotate |
| A | 2-Point Arc | S | Scale |
| R | Rectangle | T | Tape measure (guides) |
| C | Circle | D | Dimension |
| N | Polygon | W | Text |
| P | Push/Pull | B | Paint (Option samples) |
| F | Offset | E | Erase (Shift hides) |
| J | Follow Me | O | Orbit |
| X | Section cut | H | Pan |
| Z | Zoom | ⇧Z | Zoom to fit |

| Also | |
| --- | --- |
| ⌘Z / ⇧⌘Z | undo / redo |
| ⌘N, ⌘O, ⌘S, ⇧⌘S | new, open, save, save as |
| ⌘I | import |
| → ← ↑ | lock the red, green or blue axis |
| Shift (while drawing) | hold the current lock |
| Esc | cancel, or close a group |
| ⌘[ / ⌘] | previous / next view |

On Windows and Linux, ⌘ is Ctrl.
