# 7. Themes and workspaces

## Themes

![Themes and layouts](../demos/themes-layouts.gif)

**Themes** (top right) sets how SketchCraft looks:

- **Theme:** Classic (neutral greys, the default, at home if you know
  SketchUp), Workshop (SketchCraft's own drafting-paper look), Studio,
  Midnight, Blueprint, Drafting Table, Cassette Deck, Synthwave and High
  Contrast. Picking one brings its layout.
- **Layout:** **Classic** docks the tool bars above the model, out of its way.
  **Floating** puts them over the model. Change it on its own here.
- **Icons:** load your own tool icons: image files named after the tools
  (`line.svg`, `push.png`…; **File names** lists them).

**Edit colors…** on any theme makes your own. **Save as my theme…** writes a
theme file (`.sketchskin`) to share; put one you're given in the themes folder.

## Workspaces

![Workspaces](../demos/workspaces.gif)

The tabs at the top arrange the app for the job:

| Workspace | For |
| --- | --- |
| **Model** | everyday modeling |
| **Arch** | walls, stairs, roofs; floor-by-floor plans; blueprints |
| **Design** | solids, bevels and rounds |
| **Previz** | scenes, the sun, the timeline and renders |

**…** next to the tabs (Customize) picks which tools are on the tool bar and
which panels show.
